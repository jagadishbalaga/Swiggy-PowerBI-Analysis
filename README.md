## 📌 Project Overview

This project is an interactive Power BI dashboard created to analyze Swiggy restaurant data.

The objective is to explore restaurant categories, food types, ratings, prices, locations, and other business-related insights using Power BI.

## 🛠️ Tools Used

- Power BI
- Power Query
- DAX
- Data Visualization

## 📊 Analysis Performed

- Data cleaning and transformation
- Removed/handled missing and inconsistent values
- Analyzed restaurants by category
- Analyzed Veg vs Non-Veg food types
- Analyzed average price by category
- Analyzed restaurants by state
- Analyzed restaurant ratings
- Created interactive slicers
- Created KPI cards
- Designed an interactive dashboard

## 📈 Dashboard Visuals

- Restaurants by Category
- Food Type — Veg vs Non-Veg
- Average Price by Category
- Restaurants by State
- Restaurant Rating Analysis
- KPI Cards
- Interactive Slicers

## 🎛️ Interactive Filters

- State
- City
- Category
- Rating
- Food Type

## 🔍 Key Insights

- Compared restaurant categories and their distribution.
- Analyzed the proportion of Veg and Non-Veg food.
- Compared average prices across categories.
- Explored restaurant distribution across locations.
- Analyzed restaurant ratings.
- Used interactive filters to explore the data from different perspectives.
